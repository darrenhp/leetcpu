怎么用这个站

  1. 先按知识模块补齐概念：分支预测、缓存层次、ILP、内存并行、ROB、前端、TLB、SIMD。
  2. 再按模块进入对应的题目：先读题面与约束，自己想一想瓶颈在哪。
  3. 最后对照优化报告：先看“瓶颈定位”，再看“关键改动”，最后看“常见误区”。
本站不提供代码提交与仿真。所有代码均为静态展示，可一键复制到你本地的 ChampSim / perf 环境中实测。想跑在线仿真请访问 leetcpu.com。
